# Phase 14A execution contract

Scope: parser-only; unchanged production `parse_pdf` and its existing ParsedBlock adapter versus cached MinerU online `pipeline` output. No index, retrieval, chunk-policy, QA, gold, or dependency changes.

1. Freeze PDF bytes/page counts, Development manifest and generation/mapping hashes before parsing. Reuse the first completed ZIP; capture the second PDF with the same upload contract and persistent checkpoint. Never publish bearer tokens or signed URLs.
2. Freeze grain before scoring: all 50 `(question_id, child_chunk_id)` associations, plus the fixed 21 historical missing associations. Report unique chunks separately. Multi means more than one expected child, including adjacent evidence. No success-based denominator filtering.
3. Add failing contract tests, then implement offline normalization, evaluation and JSON replay. Preserve raw block order; do not apply MinerU cleanup/reordering. PyMuPDF uses the actual production entry and upstream adapter, without invoking Parent/Child construction. Unavailable bbox/hierarchy stay null.
4. Strict preservation is an ordered, whitespace-normalized NFC character alignment against gold-page ranges (cross-page inclusive). FULL requires complete alignment and exact numeric expressions; PARTIAL requires at least 50% ordered coverage; otherwise MISSING. This is a source-text fidelity proxy, not an answer/semantic correctness metric. Retain raw strings, alignment coverage and missing fragments for inspection. Private-use characters, punctuation, OCR differences and page furniture are not silently corrected.
5. Numeric units/comparators/ranges and multiplicity are retained as expressions. Compare against aligned evidence spans, not unrestricted page numbers. Report numeric-bearing evidence exact/total and expression counts. Strict failures caused by source glyphs/layout must be distinguished in the report.
6. Structural inspection uses rendered original pages, not gold's possibly incorrect reading order. Table intactness requires verified headers, cells, value associations and spans; readable HTML alone is not correctness. Review the three explicitly table-labelled gold pages, and state that subset's limits. Inspect procedure/warning/column examples and page/bbox correspondence; do not extrapolate a sample accuracy to all pages. Frozen section paths are coarse and not reliable deep hierarchy gold.
7. Per-evidence deterministic classifications use strict preservation status then numeric fidelity; identical incomplete results are BOTH_BAD. Structure findings are separate, preventing subjective overrides of the reproducible scores. Publish overall, historical21 and overlapping type breakdowns, fragments/locations, limitations and all six promotion-gate checks. Unknown gates cannot pass.
8. Replay saved normalized records without network and assert identical metrics. Run focused tests and project Ruff (also explicitly lint evaluation scripts). Commit only scoped source/tests/report/sanitized JSON. Stop after Phase 14A.
